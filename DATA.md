# Data and full-run artifacts

The dashboard runs from the compact, committed files in `dashboard/data/` and
does not need any of the large artifacts listed below. Those artifacts are
needed only to regenerate or retrain the full research pipeline. The original
copies for this project are on a **friend's laptop**.

Approximate sizes are based on the local copies where available, script
documentation, or the full-run row counts. Sizes vary with compression and
serialization versions.

The compact dashboard fixtures are `dashboard/data/test_predictions.parquet`,
`dashboard/data/sample_borrowers.parquet`,
`dashboard/data/sample_sequences.parquet`, and the JSON files beside them. They
are the only parquet/json data exceptions to the repository's broad data-file
ignore rules.

The optional four-agent demo reads the fixed subsample ID/context tables and
the surrogate rule report from `data/processed/` and `reports/`. These support
files are not needed to launch the dashboard or view its saved model results;
without them, the Explorer marks the fuzzy label unavailable and the workflow
shows which input is missing. Agent methods and outputs are unchanged.
